## Steps

1. Built `smcpd`, `smcpctl`, `smcp-refserver` and `smcp-session` from the commit above with `go build -trimpath` (the head of pull request #90; `internal/adapter`, `internal/session` and `cmd/smcp-session` are identical to `main` at `771cadc7fcb24d18f21215615cebcaf8f5e0d364`).
2. `smcpctl bootstrap` created a fresh instance on loopback ports 28443 (harness) and 28444 (admin) with `--notify off` and the reference server `ref`. A confidential `[[client]]` `helper-demo` was added for principal `claude-code-local` with `client_secret_hash` from `smcpctl hash-password`, and `smcpd` was started.
3. `smcpctl clients credentials --client-id helper-demo --secret-file <secret> --out creds/credentials.toml` wrote the CP-43 credential file (mode 0600).
4. Claude Code 2.1.302 (the Appendix K version in `docs/clients/matrix.json`): an MCP configuration `{"mcpServers": {"smcp": {"type": "http", "url": "https://127.0.0.1:28443/mcp", "headersHelper": "<helper.sh>"}}}`, where `helper.sh` runs `smcp-session` with `SMCP_CREDENTIALS` set to the file of step 3 and logs each run. Claude Code ran with `-p`, `--mcp-config` and `--strict-mcp-config`, `--tools ""`, `NODE_EXTRA_CA_CERTS` set to the Gateway CA, and the model `anthropic/claude-haiku-5.5` through the Vercel AI Gateway. It was asked to list the tools of server `smcp` and to call the echo tool once with `fr1212-claude`.
5. Codex CLI 0.142.2 (the Appendix K version): `export "$(smcp-session --env SMCP_AUTHORIZATION)"` with the same credential file, then `codex exec --ephemeral --ignore-user-config -s read-only` with `-c 'mcp_servers.smcp={url="https://127.0.0.1:28443/mcp",env_http_headers={Authorization="SMCP_AUTHORIZATION"}}'`, `CODEX_CA_CERTIFICATE` set to the macOS system roots plus the Gateway CA, and the model `openai/gpt-5.1-codex-mini` through the Vercel AI Gateway. The same request, with the text `fr1212-codex`.
6. `smcpd` was stopped with SIGTERM and `smcpctl journal verify` was run.

Codex also called `resources/list` and `resources/templates/list` on its own; the Gateway answered `-32601` (resources are not part of the release 1.0 catalog), and Codex continued.

Journal: one `session` event `created` with reason `SESSION_API` for client `helper-demo`, principal `claude-code-local`, template `read-only` (the first helper run created the session through the session API, FR-2.2; the second reused its access token from the credential file, CP-43); two `ref_echo` calls with `requested`, `dispatched`, `completed` and `delivered` events. `journal OK: 3 segments, 19 events, anchored at segment 3`.

The two runs cost about 0.06 USD (Claude Code) and 74,205 input tokens, 57,472 of them cached (Codex), on the AI Gateway.

## Deviations

Codex CLI 0.142.2 has no `http_headers_helper` hook (its configuration accepts `bearer_token_env_var`, `http_headers` and `env_http_headers`). The SRS statement and verification were narrowed on the same day: for Codex the helper's `--env` output feeds `env_http_headers`, which is the configuration this record demonstrates.
